# 응원단2 한글패치 / 검수161 미완성 시험판 (TEST/BETA)

**미완성 비공식 테스트 패치입니다. 완전 한글화·전체 검수 완료판이 아닙니다.**

## 무엇이 들어 있나요?

이 프로젝트는 응원단2의 한국어 번역 작업을 위한 비공식 패치입니다. 배포물에는 **게임 ROM과 세이브를 포함하지 않습니다.** 원본 게임은 사용자가 직접 준비해야 합니다.

- 버전: `161 TEST/BETA`
- 번역 검수 기준일: 2026-10-27
- BPS 제작·재현 검증일: 2026-10-28
- `161`은 검수·수정 작업 단위의 누적을 구분하는 논리 버전입니다. **161개의 순수 신규 번역이나 번역 완료율을 뜻하지 않습니다.**
- 실제 미번역과 검증 근거가 부족한 항목이 남아 있습니다. [알려진 문제와 검수 범위](KNOWN_ISSUES.md)를 먼저 읽어 주세요.

## 패치 및 지원 입력

이 릴리스는 아래 일본판 입력에 적용하는 BPS 패치입니다. 게임 파일을 직접 포함하지 않습니다.

| 배포 항목 | 상태 |
| --- | --- |
| 형식 | BPS |
| 패치 파일명 | `Ouendan2_Korean_TEST161_AO2J_r0.bps` |
| 패치 크기 | `8512565` 바이트 |
| 패치 SHA-256 | `d76eab3437e0538ccba083f904e65cd1ac05a2f12b94797257532f84d90ab5fc` |
| 패치 적용 재현 검증 | 정확한 입력에서 결과 파일과 바이트 단위 동일성 확인 |
| 적용 도구·명령 | 별도 BPS 적용 도구 사용 — [적용 방법](docs/APPLY_KO.md) |

### 지원 일본판 입력 파일

| 항목 | 기준 |
| --- | --- |
| 크기 | `134217728` 바이트 (128 MiB) |
| SHA-256 | `22c81d400ef0713638ee6d8a6a24a19ab3fcb76239117896c6ea9a5cfa83dd03` |
| 내부 타이틀 | `OENDAN2` |
| 게임 코드 / 메이커 코드 / 리비전 | `AO2J` / `01` / `0` |

지원 입력은 **위 SHA-256과 정확히 일치하는 일본판 파일**입니다. 타이틀·게임 코드·파일 크기만 같아서는 충분하지 않습니다. 입력은 번역 작업 시작 전 분석 기록의 파일 식별값과 일치하지만, 외부의 정상 덤프 인증을 받은 것으로 안내하지 않습니다. 이를 “공인 clean ROM 인증”으로 해석하지 마세요.

호환성 주의: 이미 수정된 v20·128 파일은 이 BPS의 지원 입력이 아닙니다.

GitHub Releases에서 실제 BPS 패치와 `SHA256SUMS`를 확인하세요. 저장소의 자동 생성 소스 압축파일과 실제 패치 배포물은 다를 수 있습니다. 적용 프로그램은 포함하지 않으며 [적용 방법](docs/APPLY_KO.md)에 외부 BPS 도구 사용 예시가 있습니다.

## 시작하기

1. [적용 방법](docs/APPLY_KO.md)에서 지원 입력과 준비물을 확인합니다.
2. 원본과 개인 세이브를 별도로 백업합니다.
3. 확정된 입력 해시와 일치하는 파일에만 패치를 적용하고, 다른 이름의 새 결과 파일을 만듭니다.
4. 결과 파일의 크기와 SHA-256이 위 값과 일치하는지 확인합니다.
5. [알려진 문제](KNOWN_ISSUES.md)를 확인한 뒤 테스트합니다.

## 권리와 라이선스

원작 게임 및 그 구성 요소의 권리는 각 권리자에게 있습니다. 이 프로젝트는 원작 제작사·유통사의 공식 패치가 아닙니다. ROM을 포함하지 않는다는 사실이 비공식 패치의 법적 안전성을 보장하지는 않습니다.

코드·번역·기타 기여물의 권리 및 재배포 조건이 정리되기 전까지 별도의 프로젝트 라이선스를 지정하지 않습니다. 원작 게임이나 제3자 자료에 MIT 등의 라이선스를 임의로 적용하지 않으며, 라이선스 파일이 없다는 사실을 자유로운 재배포 허가로 해석하지 마세요.
