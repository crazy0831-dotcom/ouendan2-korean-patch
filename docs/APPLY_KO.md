# 적용 방법

이 배포물은 **BPS 패치**입니다. 원본 게임과 세이브, 적용 프로그램은 포함하지 않습니다. 지원 입력을 직접 준비하고 별도의 BPS 적용 도구를 사용하세요.

## 1. 준비물

- 직접 준비한 원본 게임과 아래 식별값에 맞는 일본판 입력 파일
- `Ouendan2_Korean_TEST161_AO2J_r0.bps` 및 `SHA256SUMS`
- BPS 형식을 지원하는 적용 도구
- 원본과 개인 세이브의 별도 백업
- 원본과 다른 이름의 새 결과 파일을 저장할 공간

원본 게임이나 세이브의 다운로드 경로는 제공하지 않습니다. 다른 사람이 패치한 파일, 트리밍·수정된 파일은 이름이나 표시 버전이 같아도 지원 입력과 일치하지 않을 수 있습니다.

## 2. 입력 파일 확인

파일명으로 지원 여부를 판단하지 말고 **전체 파일의 SHA-256과 크기**를 확인합니다. 아래 값과 모두 일치해야 합니다.

| 입력 항목 | 기준 |
| --- | --- |
| 크기 | `134217728` 바이트 (128 MiB) |
| SHA-256 | `22c81d400ef0713638ee6d8a6a24a19ab3fcb76239117896c6ea9a5cfa83dd03` |
| 내부 타이틀 | `OENDAN2` |
| 게임 코드 / 메이커 코드 / 리비전 | `AO2J` / `01` / `0` |

내부 식별자만 같아서는 충분하지 않습니다. 이 입력은 번역 작업 시작 전 파일 기록과 일치하는 일본판 파일입니다. 이 안내는 외부의 정상 덤프 인증을 보장하지 않습니다. 이미 수정된 `v20`·`128` 파일은 지원 입력이 아닙니다.

### SHA-256 확인 예시

아래 파일명은 사용자가 가진 파일에 맞게 바꾸는 예시입니다.

macOS:

```sh
shasum -a 256 "input-game.nds"
```

Linux:

```sh
sha256sum "input-game.nds"
```

Windows PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath "input-game.nds"
```

해시의 영문 대소문자 차이는 무시할 수 있지만, 숫자와 문자는 모두 같아야 합니다. 다르면 적용을 중단하세요. 입력 검사를 끄거나 우회하지 마세요.

## 3. 패치 파일 확인

| 항목 | 값 |
| --- | --- |
| 파일 | `Ouendan2_Korean_TEST161_AO2J_r0.bps` |
| 크기 | `8512565` 바이트 |
| SHA-256 | `d76eab3437e0538ccba083f904e65cd1ac05a2f12b94797257532f84d90ab5fc` |

2절의 명령에서 파일명을 BPS 파일명으로 바꾸어 해시를 확인합니다. 배포 폴더 전체의 체크섬은 `SHA256SUMS`에 기록되어 있습니다.

macOS에서는 배포 폴더 안에서 `shasum -a 256 -c SHA256SUMS`, Linux에서는 `sha256sum -c SHA256SUMS`로 목록을 확인할 수 있습니다. 문서 파일도 검사하므로 원본 배포 파일을 수정한 경우 해당 항목은 일치하지 않을 수 있습니다.

입력 ROM, BPS 패치, 결과 ROM의 해시는 서로 다른 값입니다. 혼동하지 마세요.

## 4. 외부 BPS 도구로 적용

예시 도구로 [Floating IPS(Flips)](https://github.com/bates64/flips)가 있습니다. 도구는 해당 프로젝트의 안내에 따라 별도로 준비하세요. 특정 배포 버전이나 모든 운영체제에서 이 패치를 실행 검수했다는 뜻은 아닙니다.

1. BPS 적용 기능에서 `Ouendan2_Korean_TEST161_AO2J_r0.bps`를 선택합니다.
2. 2절의 SHA-256과 일치하는 일본판 입력을 선택합니다.
3. **원본과 다른, 아직 존재하지 않는 새 결과 파일명**을 지정합니다. 예: `Ouendan2_Korean_TEST161.nds`.
4. 적용이 완료되면 5절의 결과 검증을 수행합니다.

### Flips 명령줄 예시

아래는 [Flips의 공식 명령 형식](https://github.com/bates64/flips/blob/master/flips.cpp)을 따른 사용 예입니다. 실행 파일이 명령줄에서 호출 가능해야 하며, 운영체제·설치 위치에 따라 실행 파일 표기는 달라질 수 있습니다.

```sh
flips --apply "Ouendan2_Korean_TEST161_AO2J_r0.bps" "input-game.nds" "Ouendan2_Korean_TEST161.nds"
```

**실행 전에 출력 파일이 존재하지 않는지 반드시 확인하세요.** 위 명령만으로 기존 출력 보호를 보장하지 않습니다. 원본과 같은 경로, 기존 파일 또는 심볼릭 링크를 출력으로 지정하지 마세요. 체크섬 무시 옵션도 사용하지 마세요.

제작 검증에서는 프로젝트의 기존 Python 적용기를 사용했습니다. 그 스크립트는 이 배포물에 포함하지 않으며, 해당 도구에서 통과한 보호 시험을 Flips 등 다른 도구의 시험 결과로 대신하지 않습니다. [패치 검증 요약](VERIFICATION_KO.md)을 확인해 주세요.

## 5. 결과 검증

결과 파일에 대해 2절의 해시 확인 명령을 다시 실행하고 다음과 비교합니다.

```text
크기: 134217728 바이트
SHA-256: c4b076813bd3b3153537a025990bc5fab1dd61becb38bd4fbdca387e185f1b39
```

일치하지 않는 결과를 정상 161 배포본으로 취급하거나 재배포하지 마세요. 파일명을 바꾸어도 해시는 바뀌지 않습니다. 입력 불일치·패치 손상·결과 불일치 오류가 나오면 중단하세요.

## 6. 실행과 세이브

검증된 결과만 별도 테스트용으로 실행합니다. 기존 개인 세이브는 먼저 백업하고, 초기 테스트 중 원본 세이브를 덮어쓰지 마세요. 특정 환경에서 파일 보존을 확인한 사실은 모든 기기·에뮬레이터의 세이브 호환성을 보장하지 않습니다.

실행 성공이나 출력 해시 일치만으로 모든 화면·분기·난이도의 번역 및 동작 검수가 끝난 것은 아닙니다. [알려진 문제](../KNOWN_ISSUES.md)를 함께 확인해 주세요.
