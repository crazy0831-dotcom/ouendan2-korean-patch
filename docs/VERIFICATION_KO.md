## 거부 시험 7건

실제 제작 검증에 사용한 기존 적용기로 다음 오류가 거부되고 새 출력 또는 기존 파일이 보호되는 것을 확인했습니다.

1. 같은 크기의 잘못된 입력 파일
2. 끝이 잘린 패치
3. 잘못된 패치 CRC
4. 패치 CRC를 다시 계산해도 잘못된 입력 CRC
5. 패치 CRC를 다시 계산해도 잘못된 결과 CRC
6. 패치 CRC를 다시 계산해도 잘린 동작 본문
7. 이미 존재하는 출력 파일의 덮어쓰기

이 시험 결과를 별도의 외부 적용 도구에도 동일하게 적용되는 보장으로 읽지 마세요. 어떤 도구를 사용하든 입력 SHA-256을 먼저 확인하고, 원본과 기존 파일을 덮어쓰지 않는 새 출력 경로를 선택한 뒤 결과 SHA-256을 확인해야 합니다.
